# Gambit Pop Quiz

[中文说明](#chinese) | [English](#english)

![Preview](https://raw.githubusercontent.com/fangjx114514/REPO-GambitPopQuiz/main/assets/preview.png)

A Gambit-style variant enemy for R.E.P.O. No roulette table this time — he goes straight for the math.

## Features

- Adds **Gambit Pop Quiz** as a **Tier 2 enemy**.
- Locks your view like Gambit and starts a quick math question.
- Press **A** for the left answer or **D** for the right answer.
- Answer correctly to earn a money bag.
- Wrong answers or running out of time will deal 50 damage.

![Math quiz demo](https://raw.githubusercontent.com/fangjx114514/REPO-GambitPopQuiz/main/assets/demo.png)

## Notes

This enemy does not replace the Gambit.
Requires **REPOLib**.

# 中文说明

[English](#english) | [中文说明](#chinese)

![预览](https://raw.githubusercontent.com/fangjx114514/REPO-GambitPopQuiz/main/assets/preview.png)

一个 R.E.P.O. 的 Gambit 变体敌人。他不再抽转盘，而是当场做数学题。

## 功能

- 添加 **Gambit Pop Quiz**，作为 **Tier 2 敌人**。
- 像 Gambit 一样锁定你的视角，并开始一道数学题。
- 按 **A** 选择左边答案，按 **D** 选择右边答案。
- 答对会获得一个钱袋子。
- 答错，或者超时，会受到伤害。

![数学题交互演示](https://raw.githubusercontent.com/fangjx114514/REPO-GambitPopQuiz/main/assets/demo.png)

## 说明

不会取代原本的转盘怪。
需要 **REPOLib**。
