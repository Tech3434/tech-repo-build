# RobeCalling

The Arctic Phone's ringtone is now "Robe is my wife," the song from Semiwork's YouTube channel. Every time a phone rings in-game, that's what plays, from the top. The phone screen gets a matching Robe makeover while it rings. That's it. That's the mod.

Install it. Find a phone. Wait for it to ring. You'll know.

Client-side. You hear the song if you have the mod, nobody else has to install anything. Works in singleplayer and multiplayer. It never touches when or why a phone rings (the host decides that), so it can't desync a lobby.

## Install

Gale, r2modman or the Thunderstore app: install it like any other mod.

By hand: put `RobeCalling.dll` and `RobeCalling.bundle` together in `BepInEx/plugins/RobeCalling/`. The DLL loads the bundle from the folder it sits in, so if the bundle is missing you get the stock ringtone and a warning in the BepInEx log.

> Works on R.E.P.O. v0.4. v1.0.2 and earlier won't load on v0.4, so grab the latest.
