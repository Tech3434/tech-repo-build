# Possessed Cart

Your friends keep dying? Make them work even after death! From now on, if a dead player's head ends up inside a cart, they take control of it!

P.S. Watch out for pits! And don't forget the cannons.

> **Every player in the lobby must have this mod installed, on the same version.**

## Features

- **Possessed Cart.** A dead player's head inside the cart's cargo takes control of the cart (T.L.ZH.K.).
- **Cart Stamina.** Driving slowly drains stamina, while sprinting drains it much faster. Stamina regenerates while the cart is stationary or being pulled by a living player.
- **Weapon.** A dead player can fire weapons mounted on the T.L.ZH.K. cart at the cost of 50% of its maximum stamina. If there isn't enough stamina, the shot will still fire, but control will be interrupted for 20 seconds.
- **Living Player Priority.** Living players have priority when it comes to controlling the cart.

## Controls

| Action | Default key |
|---|---|
| Drive / steer | `W` `A` `S` `D` |
| Sprint | `Shift` |
| Aim (hold) | Right Mouse |
| Fire (only while aiming) | Left Mouse |
| Toggle drive / spectate mode | `F` |
| Let go of the cart | `X` |

All keys can be changed in the config.

## How to use

1. Simple. Kill your friend :)

## Configuration

The config file is `BepInEx/config/fyiron.possessedcart.cfg` (created on first launch).
- **Language**: Auto / English / Russian.
- **Speeds, acceleration, stamina costs and regeneration**, camera distances, and all keybinds.
- **Host settings** (`Upgrades`): `PossessedCart` and `Weapon` can be turned off. `PortabilityBooks` (0-10) reduces cargo weight, while `FixationLevel` (0-9) makes cargo stick together and follow the cart. Both are disabled by default.

## Возможности
- **Одержимая тележка.** Голова мёртвого игрока, лежащая в грузе тележки, получает управление Т.Л.Ж.К.
- **Стамина тележки.** Движение тратит её медленно, ускорение быстро. Восстанавливается, пока тележка стоит или пока её тащит живой игрок.
- **Оружие.** Мертвец может стрелять из вооружения на Т.Л.Ж.К ценой 50% максимальной выностивости. в случае нехватки выстрел состоится. но управление прервётся на 20 секунд
- **Приоритет** Живой игрок имеет повышение приоритет на управление тележкой.

## Управление
| Действие | Клавиша по умолчанию |
|
| Ехать / рулить | `W` `A` `S` `D` |
| Ускорение | `Shift` |
| Прицеливание (удерживать) | ПКМ |
| Выстрел (только при прицеливании) | ЛКМ |
| Переключить управление / наблюдение | `F` |
| Отпустить тележку | `X` |

Все клавиши меняются в конфиге.

## Как пользоваться
1. Всё просто. Убейте своего друга)

## Настройки
Файл `BepInEx/config/fyiron.possessedcart.cfg` (создаётся при первом запуске).
- **Language**: Auto / English / Russian.
- **Скорости, разгон, расход и восстановление стамины**, расстояния камеры, все клавиши.
- **Настройки хоста** (`Upgrades`): `PossessedCart` и `Weapon` можно отключить. `PortabilityBooks` (0-10) уменьшает вес груза, `FixationLevel` (0-9) заставляет груз держаться вместе и следовать за тележкой. По умолчанию оба выключены.
